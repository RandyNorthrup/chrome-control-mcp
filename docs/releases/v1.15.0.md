# Actions say what they changed, and forms fill in one call

Chrome Control MCP 1.15.0 makes every action report what it did to the page, lets an action return
the page in the same call, fills a whole form in one call, and answers in one line when a page has
not changed.

## Every action says what it changed

A click, keystroke, scroll or navigation now ends its reply with `changes`:

- `dom`: `"none"`, `"some"`, `"many"`, or `"new document"` when the tab loaded another page;
- `url` and `title` when they changed, `dialog` when one opened, `console_errors` when the page
  logged errors, and `focus` when an element took focus (`textbox "Email"`).

`dom: "none"` is the one that saves the most: the page shows nothing new, so there is nothing to
read again. Agents used to take a whole snapshot to find that out -- on a public benchmark, more
than half of the steps within a page change nothing. It adds no waiting.

## The page in the same call

Pass `snapshot: true` to any action and its reply ends with a snapshot of the page, taken once the
page has settled (100 ms without a change, at most 1.5 s). Its refs work at once: one call and one
turn instead of an action and then a look.

## A form in one call

`browser_fill_form` takes `fields: [{ref, value}]` and fills text fields, selects (by the option's
text), checkboxes and radios in order. It stops at the first field that cannot take its value and
says which, and how many before it were filled. Text fields are set the way frameworks such as
React expect, so their state sees the change.

## An unchanged page in one line

`browser_snapshot` with `if_changed: true` answers `unchanged since snapshot 3 (41 elements)` when
nothing changed, and otherwise returns the whole outline with a `*` before each new ref. It is
opt-in, because an agent whose earlier snapshot has left its context needs the whole page.

## Updating from 1.14

Nothing to do. Every reply keeps what it carried and gains `changes`; the new arguments are
optional. The tool catalog grows by about 2 KB, to 45,624 bytes for 55 tools.
