Chrome Control MCP 1.0.0 is the first public standalone release: visible, local Chrome control for
AI assistants through 43 strict-schema MCP tools.

## Highlights

- Semantic accessibility snapshots with stable refs
- Real click, type, key, hover, drag, select, scroll, dialog, and media input
- Viewport and full-page PNG capture with guarded coordinate actions
- Tabs, windows, groups, emulation, storage, cookies, permissions, downloads, print, and HTTP auth
- Visible pink control frame, AI CONTROL badge, and agent cursor
- Same-user native bridge over a protected Windows named pipe or owner-only Unix socket
- Reversible current-user native-host registration with no administrator or signing key
- Windows x64, Linux x64, macOS ARM64, and macOS x64 unsigned archives

Every archive is built and tested on a clean GitHub-hosted runner. `SHA256SUMS.txt` covers all four
assets. See `RELEASES.md` inside an archive for verification, unsigned-build, and setup details.

## Verification

- 9 native and extension suites
- Warnings-as-errors under MSVC, GCC, and Clang
- clang-tidy, exhaustive cppcheck, Semgrep, Gitleaks, npm audit, ASan+UBSan, and TSan gates
- 43/43 live MCP tools and 97/97 full-browser E2E cases through real Chrome on Windows
- Public UI Playground navigation, snapshot, typing, ref click, and screenshot

Live Chrome E2E on physical Linux and macOS desktops remains a documented claim boundary; clean
native builds, tests, packaging, dependency inspection, and staged MCP smoke checks run on both.

its [open-source repository](https://github.com/inflectra/ui-test-automation-playground) for the
