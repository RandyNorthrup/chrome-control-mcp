Chrome Control MCP 1.8.2 makes `browser_release` close everything an agent opened.

## Fixed

- **Released agents no longer leave tabs behind.** An agent that released its tab by `tab_id` -- as
  every agent sharing a server is told to -- let go of that one tab only. The popups its clicks had
  opened, and any other tab it had opened, stayed open and held for as long as its editor ran. Now
  a release by `tab_id` takes the agent's tabs: that tab, every tab opened from it, and, for an
  agent that named itself with `agent`, every tab under that name. Other agents' tabs are left
  alone.
- **A tab that will not close is never reported as closed.** Chrome refuses to close a tab while
  you are dragging one. That refusal was ignored: the reply said "closed" and the tab stayed in an
  AI group nobody held. The close is now retried, and a tab still open afterwards is handed back to
  you and listed in `not_closed`.

## Updating

- The bridge protocol is unchanged, so the extension does not reload itself: press reload on
  Chrome Control MCP at chrome://extensions after updating.
- Restart any editor or agent that was running before the update, so it starts the new server.
